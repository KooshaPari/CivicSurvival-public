# Support

## Where to get help

### In-game problems / "it's not working"

- **Discord** (fastest): <https://discord.gg/nhytdnKFeW> — the `#civic-survival`
  channel is monitored by the maintainer and several experienced players.
- **User guide**: [`USER_GUIDE.md`](USER_GUIDE.md) — covers installation, common
  scenarios, and FAQ.
- **Paradox Mods page**: <https://mods.paradoxplaza.com/mods/147665> — check
  the comments for known issues.

### Bugs and reproducible issues

Please open a GitHub issue using the **Bug report** template. A good report
includes:

1. The mod version (`Properties/PublishConfiguration.xml` or the in-game mod
   manager).
2. The game version and platform (Steam / Paradox Launcher / MS Game Pass).
3. A save file or specific steps to reproduce.
4. Your `Player.log` (Cities: Skylines II logs are at
   `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Player.log`).

### Security issues

**Do not open a public issue.** See [`SECURITY.md`](SECURITY.md).

### Discussions and feature ideas

- Use GitHub Discussions for non-urgent conversation, road-map questions, and
  longer-form ideas.
- Use the **Feature request** issue template for concrete proposals.

## What this repository is

This is the **public source mirror** of the Civic Survival mod. It is published
for transparency (auditable mod behavior, no hidden telemetry). The build
tooling, the mod-loading kit, and the city-host integration are intentionally
absent from this snapshot.

If you are a player: you do not need anything from this repository — install
from [Paradox Mods](https://mods.paradoxplaza.com/mods/147665).
