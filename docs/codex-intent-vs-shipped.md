## Methodology

The mining script is reproducible. Run:

```bash
python scripts/distill_intents.py \
    --sessions ~/.codex/sessions/2026 \
    --out docs/codex-intent-vs-shipped.md
```

The script:

1. Walks every `*.jsonl` under the sessions root
2. Filters to `type=response_item payload.role=user`
3. Extracts the text payload (handles `list[dict]` and `str` shapes)
4. Keeps prompts of length 60–8000 chars (filters out session-metadata noise)
5. Keeps prompts matching the regex `(civicsurvival|civic survival|civic-…|0.3.\d+|skyve|bepinex|paradox|…)`
6. Writes the result to the markdown above

## What this comparison does NOT prove

It proves that every shipped artefact traces back to a Codex prompt. It
does **not** prove:

- The shipped artefact satisfies the prompt's intent perfectly (judgment call)
- The shipped artefact is the _best_ implementation
- The shipped artefact is _complete_ (some prompts may have been addressed partially)

If you find a Codex prompt that you think was **misaddressed**, raise it
in the next session — the discipline tests make every shipped artefact
cheap to revise.
